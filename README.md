# mojePortfolio

Moje portfolio stron internetowych i aplikacji webowych.

## Demo

Strona online:

https://krejzolix-stack.github.io/portfolio/

## Projekty

- AutoClean — strona studia detailingu samochodowego
- FORNO — strona włoskiej restauracji
- QuickQuote — kalkulator wyceny strony internetowej
- TaskFlow — aplikacja do zarządzania zadaniami
- WeatherDash — aplikacja pogodowa z API
- BudgetFlow — aplikacja do zarządzania budżetem
- StatTrack — dashboard do analizy danych
- ClientBoard — mini CRM do zarządzania klientami

## Technologie

- HTML
- CSS
- JavaScript
- localStorage
- API
- GitHub Pages

## O projekcie

Portfolio powstało jako część mojej nauki tworzenia stron internetowych i aplikacji webowych. Projekty pokazują m.in. responsywny layout, obsługę formularzy, filtrowanie danych, localStorage oraz pracę z zewnętrznym API.
